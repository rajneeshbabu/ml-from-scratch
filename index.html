What is implemented

Five algorithms, one notebook

Each section follows the same four steps: the idea, the code, the check against scikit-learn, and a plot. The implementations are deliberately plain — small functions, no class hierarchies.

01

Linear regression & ridge

Minimise the squared error. Setting the derivative to zero gives one equation that can be solved directly — no iteration needed.

(XᵀX + αI) w = Xᵀy

Gradient descent is fitted alongside it to show the two land on the same answer, and the ridge penalty is swept to show the coefficients shrink.

Coefficients match scikit-learn to 1.38e-12 (ridge: 5.33e-13)
02

Logistic regression

The same linear score, squashed through a sigmoid and trained on the log-loss. The gradient comes out as “X transpose times the error” — the same shape as linear regression's, which is not a coincidence.

∇J = Xᵀ(p − y) + λw

There is no direct solve this time, so it is fitted twice: gradient descent, and Newton's method using the second derivative.

Newton settles in 8 steps; coefficients match scikit-learn to 7.65e-07
03

Principal component analysis

Find the directions the data varies along most. They are the eigenvectors of the covariance matrix, and each eigenvalue is the variance along that direction.

C w = λw · C = Xᶜᵀ Xᶜ / (n − 1)

Implemented both ways — via the SVD (better conditioned, never forms C) and via eigenvectors of the covariance matrix — and the two are checked against each other.

Components and variance ratios match scikit-learn to 0.00e+00
04

Neural network with backpropagation

One hidden layer, written with four named arrays rather than a general list of layers. With softmax output and cross-entropy loss the messy derivative collapses to just the error over the batch size — which is why those two are always paired.

∂L/∂z_out = (p − y) / n

Trained with ordinary mini-batch gradient descent. Since the gradients were derived by hand, a gradient check compares each one to the slope measured by nudging the weight.

Hand-derived gradients agree with measured slopes to 3.86e-09
05

Support vector machine, dual form

Rewriting the margin problem in terms of Lagrange multipliers gives a form where the data appear only as inner products — so swapping in a kernel makes the boundary curved for free.

max Σαᵢ − ½ ΣΣ αᵢαⱼ yᵢyⱼ K(xᵢ,xⱼ), 0 ≤ αᵢ ≤ C, Σαᵢyᵢ = 0

Because Σαᵢyᵢ must stay at zero, no multiplier can move alone — so SMO updates two at a time, and the update has a closed form.

Same accuracy and the same 102 support vectors as scikit-learn; boundary correlation 1.0000

Design choices

Kept simple on purpose

The point of writing these by hand is being able to explain them, so readability was chosen over generality everywhere it mattered.

Plain functions, not classes

fit_linear(X, y, alpha) and predict_linear(X, w) — no base classes, no inheritance, no framework-shaped abstractions.

Four named arrays instead of a layer loop

The network keeps W1, b1, W2, b2 explicitly. One hidden layer is enough to show what backpropagation does, and the backward pass is six lines you can point at.

Plain gradient descent, no Adam

Mini-batch SGD scores 97.78% on digits against scikit-learn's 97.33%. The extra optimiser machinery would not have bought anything here.

Simplified SMO, and the cost of it

The second multiplier is picked at random rather than by a heuristic — shorter to read, same boundary. The trade-off is real and visible: thousands more updates leave the constraint Σαᵢyᵢ = 0 drifting by 4.9e-06 in absolute terms, so the notebook checks it relative to the size of the multipliers and says why in a comment.

The point

Questions this is meant to survive

  1. Why linear regression has a direct solution and logistic regression does not.
  2. What ridge actually does to the coefficients, and why the intercept is left out of it.
  3. Why Newton's method needs so few steps, and what it costs per step.
  4. Why the eigenvalue of the covariance matrix is the variance along that direction.
  5. Why softmax and cross-entropy are always used together.
  6. Why a gradient check can fail even when the gradient is correct.
  7. Why the SVM dual lets you swap in a kernel but the primal does not.
  8. Why SMO has to update two multipliers at once instead of one.
